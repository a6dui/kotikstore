# Kotik Store — Telegram Mini App (TMA) Frontend

⚡ Высококонверсионный интерактивный Telegram Mini App для витрины цифровых подписок и ИИ-сервисов (**ChatGPT Plus**, **Gemini Advanced**, **Claude 3.7 Sonnet Pro**, **Grok AI**, **ElevenLabs**, **CapCut Pro**), выполненный в стилистике фирменного маскота Kotik Store.

---

## 🎨 Визуальная концепция и дизайн
- **Фон:** Глубокий космический черный (`#07040d`) с радиальными неоновыми свечениями токсичной мадженты (`#ec4899`), электрического фиолетового (`#9333ea`) и кибер-циана (`#06b6d4`).
- **Hero-баннер с маскотом:** Фирменный кот с атомным взрывом, держащий логотипы ChatGPT и звезду Gemini над граффити-надписью Kotik Store, анимированный мягким парением (`float`) и неоновой подсветкой.
- **Glassmorphism:** Полупрозрачные карточки (`bg-white/5`, `backdrop-blur-md`, `border border-white/10`) с индивидуальной неоновой подсветкой под бренд каждого сервиса.

---

## 🚀 Стек технологий
- **React 19 + TypeScript + Vite 8**
- **Tailwind CSS v4** с кастомными неоновыми классами и анимациями
- **Lucide React** (иконки интерфейса) + кастомные векторные SVG-логотипы ИИ-брендов
- **Canvas-Confetti** для праздничного салюта при оплате и активации бонусов
- **Telegram WebApp SDK** (`window.Telegram.WebApp`):
  - Автоматический `expand()` на весь экран смартфона
  - Настройка цвета шапки (`setHeaderColor`) и фона (`setBackgroundColor`)
  - Поддержка виброотклика **HapticFeedback** (`impactOccurred`, `notificationOccurred`, `selectionChanged`)
  - Извлечение данных пользователя (аватар, имя, username) с безопасным фоллбеком

## 📱 Функционал приложения

1. **Sticky Top Header:**
   - Аватар и имя пользователя из Telegram (или гостевой профиль с котиком).
   - Интерактивный виджет баланса (`$0.00`) с кнопкой мгновенного пополнения.

2. **Hero-секция & Статус-бар:**
   - Анимированный арт маскота Kotik Store.
   - Плашки доверия: «⚡ Моментальная автовыдача 24/7», «🛡️ Гарантия на весь срок», «⭐ Рейтинг 4.9/5».

3. **Поиск и фильтрация:**
   - Живой поиск нейросетей по названию и описанию.
   - Категории с бейджами: `Все (6)`, `Текст и Код (4)`, `Голос и Видео (2)`.

4. **Витрина товаров (Сетка 2 колонки на мобильных):**
   - **ChatGPT Plus** (от $5/мес, 🔥 ХИТ ПРОДАЖ, OpenAI Emerald)
   - **Gemini Advanced** (от $10/мес, ✨ ВЫБОР КОТИКА, Gemini Rainbow)
   - **Claude 3.7 Sonnet Pro** (от $24/мес, 💻 ТОП ДЛЯ КОДА, Anthropic Orange)
   - **Grok AI / X Premium+** (от $16/мес, 🚀 БЕЗ ЦЕНЗУРЫ, xAI Silver)
   - **ElevenLabs Pro** (от $6/мес, 🎙 AI ОЗВУЧКА, Electric Indigo)
   - **CapCut Pro** (от $4/мес, 🎬 ДЛЯ РИЛС/ТИКТОК, Neon Cyan)

5. **Интерактивный Bottom Sheet (Шторка выбора тарифа):**
   - Описание, преимущества и чек-лист возможностей.
   - Выбор типа подключения (Общий / На личный аккаунт / Инвайт / QR).
   - Выбор срока (1 / 3 / 6 / 12 мес.) со скидками до 25% и пересчетом цены в реальном времени.
   - Поле ввода email/Telegram для активации на личный аккаунт.
   - Кнопка оформления заказа.

6. **Окно оплаты (Checkout):**
   - Выбор метода: **CryptoBot**, **СБП / Карта РФ**, **Telegram Stars**, **Баланс магазина** (оплата в 1 клик).
   - Анимация обработки платежа, салют конфетти и автогенерация ключа/логина.

7. **Пополнение баланса:**
   - Быстрые суммы (`+$5`, `+$10`, `+$25`, `+$50`, `+$100`) и произвольный ввод.
   - Калькулятор конвертации в рубли и USDT.

8. **Вкладка «Мои подписки»:**
   - Предустановленный активный заказ ChatGPT Plus с ключом и инструкцией.
   - Сохранение и отображение всех купленных в приложении подписок.
   - Однокнопочное копирование данных для входа с виброоткликом.

9. **Вкладка «Поддержка»:**
   - FAQ-аккордеоны с частыми вопросами.
   - Быстрые кнопки связи с `@KotikSupport` и перехода в канал.
   - Активация промокодов (попробуйте ввести `KOTIK` для получения бонуса +$5).

## 🔗 Подключение к Telegram Bot

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Создайте бота или выберите существующего через `/mybots`.
3. Перейдите в **Bot Settings** -> **Menu Button** -> **Configure menu button**.
4. Введите URL задеплоенного приложения (например, с Vercel / Cloudflare Pages / ngrok) и название: `🛍️ Открыть магазин`.
